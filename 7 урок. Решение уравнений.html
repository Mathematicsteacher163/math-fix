543. Решите уравнение:
а) \((12 - x) - (3x + 4) = -x - 1\)
б) \(15 + (6x - x + 2) = 5x\)
в) \((2 + x) + (18 - 4x) = -(6x - 2)\)
г) \(-(0{,}5x + 0{,}2) = x - (1{,}5x + 0{,}1)\)
д) \(2x + (1{,}5 - 3x) = 1 - (x + 0{,}7)\)
е) \(8 - \left(x + \dfrac{1}{3}\right) = -\left(2x + 7\dfrac{1}{3}\right)\)

а) \((6 - x) + (12 + x) - (3 - 2x) = 15\)

в) \(8{,}2x - (5{,}8x + 4) = -(0{,}6x - 1)\)
г) \(0 = \left(\dfrac{1}{6} - x\right) - \left(x + \dfrac{1}{3}\right) + \left(2x - \dfrac{1}{3}\right)\)
д) \(5x - 8x = -(3 + 2x) - (x + 3)\)
е) \((1{,}6 + x) + (2{,}4 - 2x) + (x + 7) = 0\)

560. Решите уравнение:

в) \(\dfrac{5x}{4} - x + 1 = \dfrac{1}{2}(3 - x)\)
