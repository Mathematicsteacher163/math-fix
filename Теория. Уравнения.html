Корень уравнения и равносильность

🔑 Корень уравнения

Значение переменной, при котором уравнение превращается в верное равенство.

Решить уравнение — найти все корни или доказать, что их нет.

Пример: \(3x - 6 = 0\)

При \(x=2\): \(3\cdot2 - 6 = 0\) — корень.

При \(x=5\): \(3\cdot5 - 6 = 9 \neq 0\) — не корень.

⚖️ Равносильные уравнения

Уравнения с одинаковыми корнями (или оба без корней).

Свойства:

  • Перенос слагаемых со сменой знака.
  • Умножение/деление обеих частей на число \(\neq 0\).

Пример: \(2x - 4 = 6\) и \(2x = 10\) — равносильны (\(x=5\)).

Как решать уравнения

🔹 Перенос

\(x + a = b \Leftrightarrow x = b - a\)

🔹 Умножение / деление

\(k \cdot x = b \Leftrightarrow x = b / k\)

Пример решения:

\(5x - 7 = 3x + 9\)

1. Переносим с заменой знака: \(5x - 3x = 9 + 7\)

2. Приводим подобные: \(2x = 16\)

3. Делим на 2: \(x = 8\)

Линейные уравнения и дроби

\(ax + b = 0\)

  • \(a \neq 0\) — один корень \(x = -b / a\)
  • \(a = 0, b = 0\) — бесконечно много корней
  • \(a = 0, b \neq 0\) — корней нет

Дроби (ОДЗ)

Знаменатель не равен нулю!

\(\frac{A}{B} = 0 \Leftrightarrow A = 0, B \neq 0\)

Пример: \(\frac{x - 2}{x + 1} = 0 \Rightarrow x = 2\) (т.к. \(x \neq -1\)).

Произведение скобок равно нулю

Если \(A \cdot B = 0\), то хотя бы один из множителей равен нулю.

\((x - a)(x - b) = 0 \Leftrightarrow x = a\) или \(x = b\)

Примеры:

1) \((x - 3)(x + 5) = 0\)

\(x - 3 = 0 \Rightarrow x = 3\)
\(x + 5 = 0 \Rightarrow x = -5\)

Ответ: \(-5; 3\).


2) \((2x - 4)(3x + 9) = 0\)

\(2x = 4 \Rightarrow x = 2\)
\(3x = -9 \Rightarrow x = -3\)

Ответ: \(-3; 2\).

Уравнения с модулем

1. Модуль равен числу

\(|x| = a \quad (a \ge 0) \Leftrightarrow x = a\) или \(x = -a\)

Пример: \(|x - 3| = 5 \Rightarrow x = 8\) или \(x = -2\).

2. Модуль равен модулю

\(|x| = |y| \Leftrightarrow x = y\) или \(x = -y\)

Пример: \(|x + 1| = |2x - 3|\)

\(x + 1 = 2x - 3 \Rightarrow x = 4\)

\(x + 1 = -(2x - 3) \Rightarrow 3x = 2 \Rightarrow x = \frac{2}{3}\)

⚠️ Важно помнить

  • Приём с произведением работает только если справа стоит 0. Иначе — переносим всё влево и раскладываем на множители.
  • После возведения в квадрат или умножения на выражение с переменной обязательно проверяй корни (могут появиться посторонние).
  • При переносе слагаемых и делении на число (не ноль) корни не теряются.
